# 🚀 GridLancer

**GridLancer** is a modern B2B client management platform built for freelancers and agencies to manage clients, projects, invoices, and communication — all in one place.

---

## ✨ Features

### 👨‍💻 Freelancer Dashboard
- Client management (add/view/delete)
- Project management (full CRUD)
- Task-based progress tracking
- Invoice system (paid/pending)
- File sharing per project
- Real-time chat (Socket.io)
- Video meetings (Jitsi integration)
- Analytics dashboard

---

### 🤝 Client Portal
- Project tracking & progress view
- File downloads (deliverables)
- Invoice management (pay & download PDF)
- Real-time chat with freelancer
- Video call access
- Complaint/report system

---

### 👑 Admin Panel
- User management (freelancers & clients)
- Plan upgrade approvals
- Complaint resolution system
- Activity monitoring
- User banning (real-time enforcement)

---

## 💎 Plans

- **Starter** – Limited features for beginners  
- **Pro** – Full features with real-time system  
- **Agency** – Team collaboration & advanced controls  

---

## ⚡ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS  
- **Backend:** Node.js + Express  
- **Database:** MySQL  
- **Real-time:** Socket.io  
- **File Uploads:** Multer  
- **Video Calls:** Jitsi Meet  

---

## 🔐 Authentication
- JWT-based authentication
- Role-based access (Freelancer / Client / Admin)

---
